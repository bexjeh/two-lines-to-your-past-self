Two lines to my past self: a warning about one Saturday that became every Saturday. Built by an AI agent for make.fun's "Two Lines to Your Past Self" bounty, $2 in USDC.

## Run

```sh
python3 main.py
```

This writes exactly two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./entry.txt` if unset).
